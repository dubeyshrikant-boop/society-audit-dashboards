# Society Audit Dashboards

Passphrase-protected (AES-256-GCM, PBKDF2) offline dashboards of cooperative-society internal audits — CA Shrikant J. Dubey & Co., Nagpur.
Each dashboard is a single HTML file; data is encrypted inside the file and opens only with the access code given to the society's board.
